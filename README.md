# My TODO App

## 概要
Python (Flask) と SQLite を使用したバックエンド構築から、APIを通じたデータ連携の基礎を実装したTodoアプリケーションです。

## 開発ロードマップ・進捗状況
- [x] **フェーズ1:** バックエンドの基礎
- [x] **フェーズ2:** バックエンドのブラッシュアップ
- [x] **フェーズ3:** フロントエンドの基礎
- [x] **フェーズ4:** フロントエンドのブラッシュアップ（複数希望予定日付設定、リマインド設定、一括編集機能の実装完了）
- [x] **フェーズ5:** バックエンドとフロントエンドの統合（Flask API経由でのブラウザデータ表示確認完了）
- [ ] **フェーズ6:** フレームワークを使ったブラッシュアップ

## フェーズ4の成果物・実装機能
- **複数日付管理機能**
  - タスクごとに「開始日」「完了予定日」「締め切り日」を個別に設定可能。
- **リマインド設定機能**
  - 締め切り日に対して、任意のタイミング（〇日前）で通知を2回まで設定可能に拡張。
- **UI/UX・編集機能の強化**
  - 「仕事」「プライベート」「学習」「その他」のジャンル整理。
  - タスクカード単位での一括編集機能とスムーズな保存処理。
