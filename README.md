# 📋 マイTodoアプリ

Python、SQLite、およびHTML/CSS/JavaScript（バニラ）を用いてゼロからスクラッチ開発しているTODOアプリです。
フロントエンドとバックエンドを個別に構築・検証したのち、段階的に統合していくプロセスを経て、システムの全体像とデータの流れを深く理解することを目的として制作しています。

---

## 🚀 開発の経緯
実務（フロントエンド2年）で培ったUI構築の経験をベースにしつつ、バックエンドのデータ操作やデータフローの理解を深めるため、身近なTODOアプリをゼロから企画・開発しました。

複雑なツールやフレームワークに最初から頼るのではなく、「まずは標準機能で動くものを作り切る」ことを最優先に設定。フェーズを細かく分け、予期せぬ不具合やデータ更新時のバグを地道に潰しながら、段階的に機能を拡張するアプローチをとっています。単なるチュートリアルの消化ではなく、プロダクトの成長プロセスそのものを体現する成果物として位置づけています。

---

## 🛠 開発の歩み

### 🔹 フェーズ 1：データベースとバックエンドの基盤づくり
- **内容：** PythonおよびSQLiteを用いたデータの保存機能の構築
- **実現した機能：**
  - タスクの追加機能
  - ステータス管理付きの一覧確認
  - コンテンツの変更や削除機能

### 🔹 フェーズ 2：フェーズ1の機能改善
- **内容：** 実際に入力した際に発生した不具合や、データの更新に関する不具合の修正
- **詳細な修正内容：**
  - 全角・半角の入力対応（入力ミスによるエラーや不具合を防ぐ対応）
  - 編集・削除機能の改善（変更や削除を確実に反映）
  - 編集・削除を行ったあと、その変化が自動で一覧に即時反映されるUIの連動

### 🔹 フェーズ 3：フロントエンドの単体実装（※フェーズ1のバックエンドとは非連携）
- **内容：** 「静的」フォルダを作成し、その中にHTML、CSS、JavaScript（バニラ）を作成して画面側の実装を行う
- **できるようになったこと：** 
  - フロントエンド側の基礎知識やUIの構築を学習・実践
  - （※まずはバックエンドを紐付けず、フロントエンド単体での挙動を確立）

- **フロントエンド：** HTML、CSS、JavaScript (Vanilla)

## 💡 技術選定の理由と開発のこだわり
- **技術選定の理由：**
  馴染みのあるPythonと、ローカル環境で軽量かつ手軽にデータベースの挙動を検証できるSQLiteを採用。システムの根底にあるデータ永続化の仕組みをダイレクトに理解できるようにしました。
- **開発のスタンス・こだわり：**
  学習初期にフレームワークを導入すると裏側の仕組みがブラックボックス化する懸念があったため、あえて標準機能とバニラ環境での実装にこだわりました。「なぜこの挙動になるのか」を自分の手で泥臭く追いかけ、一つひとつの処理を腑に落としながら開発を進めることで、新しい技術に対する適応力とトラブルシューティング能力を鍛えています。
