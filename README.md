# My TODO App

## 概要
Python (Flask) と SQLite を使用し、バックエンドのデータベース構築からAPIを通じたデータ連携、フロントエンド（HTML/CSS/JavaScript）との統合までを段階的に実装するTodoアプリケーションです。

## 開発ロードマップ・実績
このアプリケーションは、以下のステップ（フェーズ）で設計・実装を進めています。

- [x] フェーズ1: バックエンドの基礎構築
  - Pythonスクリプトを用いた基本的な処理とデータ構造の理解。
- [x] フェーズ2: データベース設計とCRUD操作
  - SQLiteデータベース（todo.db）の作成およびテーブル定義。
  - データの挿入・取得・更新・削除（CRUD）を行う個別のPythonスクリプトの実装。
- [x] フェーズ3: フロントエンドの基礎実装
  - HTML/CSS/JavaScriptを用いたユーザーインターフェース（UI）の構築。
- [x] フェーズ4: アプリケーションロジックの統合
  - 個別の処理を整理し、アプリとしての機能をまとめたロジック（todo_app.py など）の構築。
- [x] フェーズ4.5: 実装の整理とブラッシュアップ
  - **UX/UIの徹底的な向上**：操作の途中で「0」や空エンターで安全に一つ前の画面に戻れるキャンセル機能や、変更・削除後に最新一覧が自動で再表示されるスムーズなループ設計を実装。
  - **アーキテクチャ設計（MVCモデルへのアプローチ）**：アプリの心臓部とデータベース操作のクエリを `model/model.py` に分離し、保守性と責務の分離を意識。
  - **堅牢性とセキュリティの強化**：Flask（`app.py`）のデータベース接続に `with` 構文や例外処理を導入して安全性を高めつつ、ローカルの `todo.db` を `.gitignore` で適切に除外して実務のセキュリティ作法を再現。
- [ ] フェーズ5: FlaskによるAPI・フロントエンド統合
  - Flaskを用いてバックエンドとフロントエンドを繋ぎ、ブラウザ上でのデータ連携と表示を確認する（※今後実装予定）。

## 🚀 起動方法・実行手順

ローカル環境でこのアプリケーションを動かすための手順です。

### 1. 必要なライブラリのインストール
Flaskがインストールされていない場合は、以下のコマンドを実行します。
$ pip install flask

### 2. データベースの初期化
必要に応じて、以下のスクリプトを実行してデータベースおよびテーブルを準備します。
$ python create_db.py
$ python create_table.py

### 3. アプリケーションの起動
Flaskサーバーを起動します。
$ python app.py

起動後、指定されたローカルURLにブラウザでアクセスしてアプリケーションを確認できます。
