# 📋 マイTodoアプリ

PythonとSQLite、そしてHTML/CSS/JavaScriptを使って作成しているTODOアプリです。

## 🛠 開発の歩み

### 🔹 フェーズ1：データベースとバックエンドの土台づくり
- **内容**
  - PythonとSQLiteを用いたデータの保存機能の構築
- **実現した機能**
  - タスクの追加機能
  - ステータス管理付きの一覧確認
  - 内容の変更や削除機能

### 🔹 フェーズ2：フェーズ1(データベースとバックエンドの土台づくり)の機能改善
- **内容**
  - 実際に入力した際に発生したズレや、データの更新に関する不具合を修正
- **詳細な修正内容**:
  - **全角・半角の入力対応**
    - 入力時のズレによるエラーやその際の不具合を防ぐための対応を実施
  - **編集・削除機能の改善**
    - 登録したタスクの変更や削除を行えるように修正
    - 編集や削除を行ったあと、その変化が自動で一覧に反映されてすぐに最新の状態を確認できるように改善

### 🔹 フェーズ3：フロントエンドの単体実装（※フェーズ1のバックエンドとは非連携）
- **内容** 「静的」フォルダを作成し、その中にHTML、CSS、JavaScript（バニラ）を作成して画面側の実装を行う
- **できるようになったこと**
  - フロントエンド側の基礎知識やUIの構築を学習・実践
  - ※現時点ではフェーズ1のバックエンドとはまだ紐付けておらず、フロントエンド単体での実装

## 🛠 つかっている技術
- **バックエンド**: Python, SQLite
- **フロントエンド**: HTML, CSS, JavaScript (バニラ)

## 🚀 これからの目標
- 独立して作ったバックエンドとフロントエンドを繋ぎこむ。
- さらに使いやすいアプリへとブラッシュアップしていく。
