# 📝 My TODO App

## 📌 概要
実務を想定したシンプルで、後から機能を追加しやすいTODOアプリケーションです。

## 🛠️ 使用技術 (フェーズ3：フロントエンド)
* **HTML5**
* **CSS3**: カード型レイアウトによる視認性の向上
* **JavaScript (Vanilla)**: DOM操作、動的なタスク追加・削除・編集

## ✨ こだわったポイント
* **カード型レイアウトの採用**
  * 入力フォームやタスク項目を1つずつの枠で囲み、情報のかたまりを見やすく整理しました。
* **タスク情報の拡張**
  * ジャンル、優先度、予定日を追加し、実用的なタスク管理ができるように設計しています。
